# Data Provenance

## Repository evidence

The committed source file is `data/pharmacy_data.csv`.

The executed notebook shows 11,825 records and nine original columns:

1. Medicine Name
2. Composition
3. Uses
4. Side_effects
5. Image URL
6. Manufacturer
7. Excellent Review %
8. Average Review %
9. Poor Review %

Sample rows begin with Avastin 400mg Injection, Augmentin 625 Duo Tablet, Azithral 500 Tablet and Ascoril LS Syrup, and image URLs use the `onemg.gumlet.io` host.

## Source vs derived fields

The nine original columns are the source-data layer.

Retail price, cost, profit, sales quantity, expiry date, competitor price and movement/risk classifications are synthetic fields generated by this project. They must not be presented as factual market or pharmacy records.
